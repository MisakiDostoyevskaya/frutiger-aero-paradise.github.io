# Frutiger Aero

Un escritorio web interactivo inspirado en Frutiger Aero y Windows Vista, hecho con HTML, CSS y JavaScript sin frameworks.

## Incluye
- Ventanas de vidrio que se pueden arrastrar, minimizar y cerrar.
- Dock lateral para volver a abrir las ventanas.
- Cuatro ambientes visuales: cielo, océano, bosque y ciudad.
- Burbujas animadas, brillo del cursor y controles de movimiento.
- Reloj y fecha locales.
- Mini acuario con peces animados.
- Notas que se guardan en el almacenamiento local del navegador.
- Reproductor con música ambiental generada por Web Audio API (no necesita archivo de audio externo).
- Diseño adaptable a móviles.

## Música
La música es un paisaje sonoro generativo sintetizado en el navegador. Por las políticas de reproducción automática, hay que pulsar Play. No se descarga ni transmite ninguna canción.
